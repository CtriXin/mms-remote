# MMSChat Protocol Spec

- Status: P0 frozen for implementation handoff
- Trace ID: `trc-20260516T082907Z-f43b858883`
- Scope: protocol and model only; no registry, store, launcher, transcript reader, live send, resume matrix, or UI integration.

## Product Boundary

MMSChat is a local-first session index and transcript cache view over Claude native sessions. Claude native project JSONL remains the transcript source of truth:

```text
/Users/xin/.claude/projects/<project-key>/<session-uuid>.jsonl
```

MMSChat stores only local index metadata needed to list, attach to, resume, and display sessions. It must not become a second chat database.

### Required Field Notes

- `mmschatId` is generated by MMS and is the app-facing stable ID.
- `nativeClaudeSessionId` is generated by MMS for owned launches and passed to Claude with `--session-id <uuid>` when possible.
- `nativeClaudeSessionStatus` is `pending` until the matching native JSONL file is confirmed.
- `authSecretRef` and `launchProfileFingerprint` are non-secret references only.
- `lastPreviewText` may come from native JSONL or raw `tmux capture-pane`; callers must treat raw capture as preview only.

## Status Transitions

Allowed transitions:

| From | To | Reason |
|---|---|---|
| `pending` | `running` | Claude process exists and launch metadata is registered. |
| `pending` | `unknown` | Session discovery is incomplete or ambiguous. |
| `running` | `idle` | Process is alive but no active turn is observed. |
| `running` | `dead` | Process exits and no safe resume metadata exists. |
| `running` | `needs-resume` | Process exits while native session metadata is available. |
| `idle` | `running` | Activity resumes in the tracked pane/process. |
| `idle` | `dead` | Liveness check confirms process exit. |
| `idle` | `needs-resume` | Liveness check confirms exit and resume metadata exists. |
| `dead` | `needs-resume` | Native session metadata is later confirmed. |
| `needs-resume` | `pending` | Resume is requested and launch is starting. |
| `needs-resume` | `running` | Resume launch is confirmed live. |
| `unknown` | `pending` | Discovery restarts with a candidate session. |
| `unknown` | `running` | Candidate is confirmed live. |
| `unknown` | `needs-resume` | Native session exists but live process does not. |

Terminal states are not destructive. `dead` does not mean native Claude history is deleted.

## RPC Envelope

All methods use the existing bridge JSON-RPC shape:

```json
{ "id": "request-id", "method": "mmschat/list", "params": {} }
```

Responses use:

```json
{ "id": "request-id", "result": {} }
```

Errors use JSON-RPC error code `-32000` with app-specific `data.errorCode`.

## RPC Methods

### `mmschat/list`

Params:

```json
{
  "includeHidden": false,
  "status": ["pending", "running", "idle", "dead", "needs-resume", "unknown"],
  "cwd": "/Users/xin/project",
  "limit": 50
}
```

Response:

```json
{
  "sessions": ["MMSChatSession"],
  "source": "registry",
  "sortedBy": "lastActivityAt"
}
```

Rules:

- Default `includeHidden` is `false`.
- Sessions sort by `lastActivityAt` descending.
- `cwd` filters only when explicitly supplied.

### `mmschat/detail`

Params:

```json
{
  "mmschatId": "mmschat_abc",
  "includeTranscript": true,
  "transcriptMode": "native-jsonl"
}
```

Response:

```json
{
  "session": "MMSChatSession",
  "transcript": {
    "source": "native-jsonl",
    "nativePathState": "confirmed",
    "messages": [],
    "rawPreviewText": null
  }
}
```

Rules:

- P0 defines shape only; P3 implements native JSONL reading.
- Raw terminal capture may populate `rawPreviewText`, but must not produce structured `messages`.

### `mmschat/attach`

Params:

```json
{
  "tmuxPaneId": "%42",
  "tmuxSessionName": "mms-remote",
  "cwd": "/Users/xin/project",
  "nativeClaudeSessionId": null,
  "provider": "kimi",
  "model": "k2",
  "launchProfileName": "work",
  "launchProfileFingerprint": "sha256:...",
  "authSecretRef": "profile:work"
}
```

Response:

```json
{
  "session": "MMSChatSession",
  "attached": true
}
```

Rules:

- `nativeClaudeSessionId` may be null while discovery is pending.
- `authSecretRef` is a reference only. Raw credentials are rejected.

### `mmschat/send`

Params:

```json
{
  "mmschatId": "mmschat_abc",
  "text": "hello",
  "clientMessageId": "uuid",
  "featureFlag": false
}
```

Response when disabled:

```json
{
  "accepted": false,
  "disabled": true,
  "errorCode": "send_disabled"
}
```

Rules:

- Send is feature-flagged off by default.
- P0 and P1 must not call `tmux send-keys`.
- S2 must validate live input safety before send can become enabled.

### `mmschat/resume`

Params:

```json
{
  "mmschatId": "mmschat_abc",
  "launchProfileFingerprint": "sha256:..."
}
```

Response:

```json
{
  "session": "MMSChatSession",
  "resumeStarted": true
}
```

Rules:

- Resume uses `nativeClaudeSessionId`, `authSecretRef`, and launch profile metadata.
- S1 must validate provider/model resume compatibility before cross-provider resume is claimed.

### `mmschat/openVisible`

Params:

```json
{
  "mmschatId": "mmschat_abc",
  "visibleApp": "auto"
}
```

Response:

```json
{
  "opened": true,
  "visibleApp": "auto"
}
```

### `mmschat/kill`

Params:

```json
{ "mmschatId": "mmschat_abc" }
```

Response:

```json
{
  "session": "MMSChatSession",
  "killed": true
}
```

Rules:

- Kill stops only the live process/pane.
- Kill must not delete native Claude project JSONL.

### `mmschat/hide`

Params:

```json
{ "mmschatId": "mmschat_abc", "hidden": true }
```

Response:

```json
{ "session": "MMSChatSession" }
```

Rules:

- Hide only changes MMSChat list visibility.
- Hide must not delete native Claude sessions or transcript cache.

### `mmschat/cache/clear`

Params:

```json
{ "mmschatId": "mmschat_abc" }
```

Response:

```json
{
  "session": "MMSChatSession",
  "cacheCleared": true
}
```

Rules:

- Clears only MMSChat-derived transcript cache.
- Must not delete Claude native JSONL or MMSChat registry identity.

## Error Codes

| Code | Meaning |
|---|---|
| `invalid_params` | Required params are missing or malformed. |
| `session_not_found` | `mmschatId` does not map to a known session. |
| `native_session_pending` | Native Claude session ID is not confirmed yet. |
| `pane_dead` | The tracked tmux pane/process is gone. |
| `busy` | Session is not safe for the requested live action. |
| `send_disabled` | Send feature flag is off. |
| `resume_failed` | Resume command failed or could not be confirmed. |
| `unsupported_method` | Method is outside the frozen MMSChat RPC surface. |
| `secret_rejected` | Params contain token/API-key-like raw credential material. |

## Redaction Rules

- Never persist API keys, auth tokens, relay `sessionId`, pairing secrets, transcript secrets, or raw provider credential material.
- Logs and errors must not print native Claude session IDs, relay IDs, or pairing identifiers in full.
- If diagnostics require correlation, use stable hashes or short non-reversible fingerprints.
- App responses may include `nativeClaudeSessionId` only as local metadata after the user already owns the paired local bridge session.

## Deletion Semantics

| Operation | MMSChat registry | Transcript cache | Live process | Claude native JSONL |
|---|---|---|---|---|
| `hide` | Set `hidden=true` | Unchanged | Unchanged | Unchanged |
| `cache/clear` | Keep record | Clear derived cache | Unchanged | Unchanged |
| `kill` | Keep record, transition status | Unchanged | Stop if live | Unchanged |
| `destroy` | Out of MVP | Out of MVP | HumanGate | HumanGate |

`destroy` and native history deletion are intentionally out of P0 and MVP.

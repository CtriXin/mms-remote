# MMS Remote Terms

MMS Remote is a self-hosted, local-first developer tool. You run the bridge,
relay, and mobile build yourself, and you are responsible for the runtime,
network, device trust, and repository access you connect to it.

The project does not provide an official hosted relay, App Store subscription,
or managed account service in this repo. Any deployment you operate should use
your own relay URL, APNs credentials, signing identity, and policy documents.
